## 🛠️ Architecture Overview

The system is built on the following technologies:

- **Android Client**: Kotlin, Java, Jetpack Compose, MVVM & Clean Architecture, Room / Realm / Firebase, Coroutines & RxJava, Retrofit & OkHttp, Dagger 2 & Koin.
- **Backend & Database**: Next.js App Router, Supabase PostgreSQL, Drizzle ORM.
